### What I can build for you

| Layer | What it means in practice |
|---|---|
| **Interface** | Native iOS in **SwiftUI** and cross-platform apps in **Flutter**: custom tab bars, glass effects, map camera animations, dark-mode design systems |
| **Architecture** | **Clean Architecture** with feature modules, **@Observable** view models and **BLoC**, **Swift Concurrency** (async/await, task groups, actors), generic API clients with mocks and caching |
| **Backend** | **Spring Boot** REST APIs with JWT security filters and global error handling, **Node.js** and **Python** services, **PostgreSQL** schema design, **Supabase** storage |
| **Device** | **MapKit**, **HealthKit**, Keychain, push notifications, real-time voice rooms, and chat powered by a **locally hosted LLM** |

### How I work

```swift
struct Karthik: Engineer {
    let platforms: [Platform] = [.iOS, .android, .web]
    let approach = "Understand the why, then build the how"

    func build(_ idea: Idea) async throws -> App {
        let api = try await Backend.design(for: idea)   // schema first
        let ui  = Interface.design(for: idea)           // then the screens
        return App(ui: ui, api: api, architecture: .clean)
    }
}
```
